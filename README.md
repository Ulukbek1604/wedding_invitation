# Свадебное приглашение

Одностраничный сайт-приглашение: конверт с сургучной печатью, Save the date, дата и место, обратный отсчёт, тайминг, дресс-код и анкета гостя.

## Как поменять данные

Всё редактируется в одном месте — блок `CONFIG` внизу файла `index.html`:
имена, дата и время, ресторан и адрес, ссылки на карты, тайминг, цвета дресс-кода,
срок ответа и номер WhatsApp для ответов гостей (`whatsapp: "996700123456"`).

Текст «Ты заставляешь меня сиять» и подписи секций — прямо в HTML.

## Как опубликовать

GitHub → Settings → Pages → Source: `Deploy from a branch`, ветка с этим файлом, папка `/ (root)`.
Через минуту сайт будет доступен по ссылке вида `https://<логин>.github.io/wedding_invitation/`.
