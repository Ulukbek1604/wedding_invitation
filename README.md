# Свадебное приглашение — Боламан и Альбина

Сайт-приглашение в четырёх вариантах оформления:

| Адрес | Вариант |
|---|---|
| `/` | Шёлк, бабочки, конверт с сургучной печатью |
| `/night` | «Ночной сад» — тёмный, со свечой и золотом |
| `/garden` | «Сад» — светлый ботанический |
| `/paper` | «Бумага» — открытка в одну краску ультрамарином |

В каждом: Save the date, дата и место с кнопкой «Как добраться», обратный отсчёт с кнопкой «Добавить в календарь», тайминг.

## Как поменять данные

В каждом файле (`index.html`, `night/`, `garden/`, `paper/`) есть блок `CONFIG` в скрипте:
имена, дата и время, ресторан и адрес, ссылки на карты, тайминг.

## Публикация

Проект статический, Vercel публикует его без сборки (Preset: Other, Root: `./`).
Каждый вариант лежит в своей папке, поэтому адреса `/night`, `/garden`, `/paper` работают без настроек.
